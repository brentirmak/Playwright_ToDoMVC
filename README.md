# ToDoMVC
This repo is for the ToDoMVC Playwright + Pytest Demo <br>
Utilizes pytest to test https://todomvc.com/examples/react/dist/ <br>
Uses the shared_page fixture to maintain session/state in a single browser<br>
Stores test results into MySQL DB<br>
Dev Environment is on Windows (Visual Studio Code) <br>
Jenkins Instance is running on Ubuntu 24.04 - Jenkins(2) <br>
